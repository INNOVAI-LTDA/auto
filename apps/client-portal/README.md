# AUTO Commercial — Portal do cliente/stakeholder

## Objetivo

Aplicação web voltada para cliente/stakeholders externos, com foco no fluxo comercial e de acompanhamento de solicitações.

## Rotas atuais

- `/`
- `/request`
- `/status`
- `/approval`

## Tema visual

Tema **AUTO Commercial**, orientado à experiência externa do cliente.

## Comandos locais

```bash
cd apps/client-portal
npm install
npm run dev -- --port 3000
```
